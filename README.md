# Dual Translator

**Version 1.3.1** · by Oleksii Pokormiakho

Dual Translator is a lightweight, mobile-friendly web app that translates one text into **two languages at the same time**. Type or dictate once, and get both translations side by side, ready to copy or listen to.

It is made for people who regularly communicate in several languages, for example translating a Dutch message into English and Ukrainian in a single step.

## Features

- **Two translations at once** from a single source text
- **Auto-translate** while you type, or translate manually with a button
- **Voice input** for the source text
- **Listen** to the source text and both translations
- **Copy, paste and clear** buttons; copying uses the selected text if there is a selection
- **9 languages**: German, English, French, Dutch, Polish, Portuguese, Russian, Turkish, Ukrainian
- **Interface in the same 9 languages**
- **Your choices are remembered**: languages and options are saved in the browser, and the 🔄 button restores the defaults
- Works on phone, tablet and desktop

## How it differs from Google Translate

| | Dual Translator | Google Translate |
|---|---|---|
| Target languages per request | Two at once | One at a time |
| Account or sign-in | Not needed | Not needed for basic use |
| Focus | Quick text translation into two languages | Full feature set (documents, images, offline mode, and more) |

Dual Translator is not a replacement for everything Google Translate offers. It is a small, focused tool for getting the same text in two languages quickly. Translation quality may differ from Google Translate.

## How to use

1. Choose the **source language** and the two **target languages**.
2. Type or paste your text, or tap 🎤 to dictate it.
3. Read the translations as they appear. With auto-translate off, press **Translate**.
4. Use 📋 to copy a text or 🔊 to listen to it.

## Tips

- Voice input works in browsers that support speech recognition, such as Chrome or Edge, and needs microphone permission.
- Listening to a text uses the voices installed on your device, so available languages may vary.
- The free translation service has a daily limit, so very heavy use may temporarily stop working.
