What is Dual Translator

Dual Translator translates the text you enter into two languages at once. You enter the text one time (type it, paste it or dictate it) and the program shows two translations side by side. You can copy or listen to each result.

For language combinations you use often there are configurations: each one stores three languages (the source and two target languages) and a set of visible buttons. You switch between them with one tap.

The interface is available in: Deutsch, English, Esperanto, Español, Français, Italiano, Nederlands, Polski, Português, Русский, Türkçe, Українська.

Main screen

  1. Information ( button): opens this window.
  2. Settings ( button): themes, interface language, configurations, visible buttons.
  3. Mode: colour mode of the chosen theme: Contrast, Normal, Evening or Night. The same selector is in the settings.
  4. Configuration buttons: quick switch between saved sets of languages. The button shows the code of the source language (for example NL, EN). The active configuration is highlighted.
  5. Source Language: the language of the text you enter.
  6. Buttons above the text: paste from the clipboard, copy the source text, play the source text.
  7. Input field: enter the source text here.
  8. Microphone (, "Voice input"): dictate in the source language. Press again to stop.
  9. Clear (): erases the source text and both translations.
  10. Auto-translate: when the box is checked, the translation appears by itself as soon as you enter text or change a language.
  11. Target Language 1 and its translation. The and buttons copy and play the translation.
  12. Target Language 2 and the second translation with the same buttons.

How to translate a text

  1. Choose the source language and the two target languages, or press the button of the configuration you need.
  2. Type the text, paste it with or dictate it with the microphone .
  3. If Auto-translate is on, both translations appear by themselves. If it is off, press the Translate button.
  4. Copy a translation with or listen to it with .
  1. "Auto-translate" box: uncheck it to translate only with the button.
  2. "Translate" button: visible only while Auto-translate is off.

Translation is done by an online service, so an internet connection is required. Free services can have a daily limit on the amount of text.

Voice input and playback

  • Dictation (). Press the button and speak in the source language. The recognised text appears in the input field. Pressing again stops the recording. The browser may ask for microphone access, and in some browsers dictation is not available.
  • Playback (). Reads the source text or a translation aloud with the voice of your device. Pressing again while it is reading stops it.
  • Clearing on dictation. In the settings you can make the input field be cleared every time you start dictating.

Configurations

A configuration stores three languages (source and two targets) and a set of visible buttons. Pressing a configuration button on the main screen loads its languages and buttons at once. Three configurations are available by default, up to six can be enabled.

If you change languages directly on the main screen, this is a temporary choice: the saved configuration stays as it was. To have such changes remembered in the active configuration, turn on "Remember main-screen languages" in the settings.

Settings

The settings window consists of blocks. Scrolling takes you from block to block. While you scroll, a fraction appears in the corner for two seconds: the number of the current block over the total number of blocks.

Theme, mode and interface language

  1. Theme: colour palette of the program.
  2. Mode: Contrast (brighter and sharper), Normal, Evening or Night. Night mode is dark and dim, so you can look at the screen calmly in the dark. It works in sync with the selector on the main screen.
  3. Interface: language of the program labels.
  4. Block number: the fraction that appears for two seconds while scrolling.

Configurations and languages

  1. Number of configurations: how many configuration buttons to show on the main screen (1–6).
  2. Configuration tabs: which configuration you are editing. The tabs in the "Languages" and "Visible buttons" blocks duplicate each other: choosing one in either place switches both blocks.
  3. Source Language of the chosen configuration.
  4. Target Language 1 of the chosen configuration.
  5. Target Language 2 of the chosen configuration.
  6. Remember main-screen languages: one box for all configurations. When it is on, languages chosen on the main screen are written into the active configuration.

Visible buttons

  1. Configuration tabs: the same as in the "Languages" block.
  2. Source buttons: paste, copy, play, microphone, clear.
  3. Translation 1 buttons: copy, play.
  4. Translation 2 buttons: copy, play.

Uncheck a box and the button disappears from the main screen for this configuration. This way you can keep only what you need. Every configuration has its own set of buttons.

Microphone and reset

  1. Clear text when the microphone starts: one box for everything. The input field is cleared before each dictation.
  2. Reset defaults (🔄): returns all settings to their original values.

Useful tips

  • All settings are saved automatically and are kept after you close the program.
  • The help and settings windows are closed with the ✕ button or the Esc key.
  • On a phone the main screen and the settings scroll in steps: each swipe moves to the next block.
  • For a language pair you use often, create a separate configuration and keep only the buttons you need.
