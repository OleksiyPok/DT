Qu’est-ce que Dual Translator

Dual Translator traduit le texte saisi dans deux langues à la fois. Vous saisissez le texte une seule fois (en le tapant, en le collant ou en le dictant) et le programme affiche deux traductions côte à côte. Vous pouvez copier ou écouter chaque résultat.

Pour les combinaisons de langues que vous utilisez souvent, il existe des configurations : chacune mémorise trois langues (la langue source et deux langues cibles) ainsi qu’un ensemble de boutons visibles. Vous passez de l’une à l’autre d’une simple pression.

L’interface est disponible en : Deutsch, English, Français, Nederlands, Polski, Português, Русский, Türkçe, Українська.

Écran principal

  1. Aide (bouton ℹ️) : ouvre cette fenêtre.
  2. Paramètres (bouton ⚙️) : thèmes, langue de l’interface, configurations, boutons visibles.
  3. Mode : mode de couleur du thème choisi : Contraste, Normal ou Nuit. Le même sélecteur se trouve dans les paramètres.
  4. Boutons de configuration : passage rapide entre les jeux de langues enregistrés. Le bouton affiche le code de la langue source (par exemple NL, EN). La configuration active est mise en évidence.
  5. Langue source : la langue du texte que vous saisissez.
  6. Boutons au-dessus du texte : 📥 coller depuis le presse-papiers, 📋 copier le texte source, 🔊 écouter le texte source.
  7. Champ de saisie : saisissez ici le texte source.
  8. Microphone (🎤, « Reconnaissance vocale ») : dictez dans la langue source. Appuyez de nouveau pour arrêter.
  9. Effacer (❌) : supprime le texte source et les deux traductions.
  10. Traduction automatique : lorsque la case est cochée, la traduction apparaît d’elle-même dès que vous saisissez du texte ou changez de langue.
  11. Langue cible 1 et sa traduction. Les boutons 📋 et 🔊 copient et lisent la traduction.
  12. Langue cible 2 et la deuxième traduction avec les mêmes boutons.

Comment traduire un texte

  1. Choisissez la langue source et les deux langues cibles, ou appuyez sur le bouton de la configuration souhaitée.
  2. Tapez le texte, collez-le avec 📥 ou dictez-le avec le microphone 🎤.
  3. Si la traduction automatique est activée, les deux traductions apparaissent d’elles-mêmes. Si elle est désactivée, appuyez sur le bouton Traduire.
  4. Copiez une traduction avec 📋 ou écoutez-la avec 🔊.
  1. Case « Traduction automatique » : décochez-la pour ne traduire qu’avec le bouton.
  2. Bouton « Traduire » : visible uniquement lorsque la traduction automatique est désactivée.

La traduction est effectuée par un service en ligne : une connexion Internet est donc nécessaire. Les services gratuits peuvent avoir une limite quotidienne sur la quantité de texte.

Saisie vocale et lecture

  • Dictée (🎤). Appuyez sur le bouton et parlez dans la langue source. Le texte reconnu apparaît dans le champ de saisie. Un nouvel appui arrête l’enregistrement. Le navigateur peut demander l’accès au microphone, et dans certains navigateurs la dictée n’est pas disponible.
  • Lecture (🔊). Lit à voix haute le texte source ou une traduction avec la voix de votre appareil. Un nouvel appui pendant la lecture l’arrête.
  • Effacement lors de la dictée. Dans les paramètres, vous pouvez faire en sorte que le champ de saisie soit vidé à chaque démarrage de la dictée.

Configurations

Une configuration mémorise trois langues (source et deux cibles) et un ensemble de boutons visibles. Un appui sur un bouton de configuration de l’écran principal charge en une fois ses langues et ses boutons. Trois configurations sont disponibles par défaut, jusqu’à six peuvent être activées.

Si vous changez les langues directement sur l’écran principal, il s’agit d’un choix temporaire : la configuration enregistrée reste inchangée. Pour que ces changements soient mémorisés dans la configuration active, activez « Mémoriser les langues de l’écran principal » dans les paramètres.

Paramètres

La fenêtre des paramètres est composée de blocs. Le défilement vous mène d’un bloc à l’autre. Pendant que vous faites défiler, une fraction apparaît dans le coin pendant deux secondes : le numéro du bloc actuel au-dessus du nombre total de blocs.

Thème, mode et langue de l’interface

  1. Thème : palette de couleurs du programme.
  2. Mode : Contraste (plus lumineux et plus net), Normal ou Nuit. Le mode Nuit est sombre et tamisé, ce qui permet de regarder l’écran tranquillement dans le noir. Il est synchronisé avec le sélecteur de l’écran principal.
  3. Interface : langue des libellés du programme.
  4. Numéro du bloc : la fraction qui apparaît pendant deux secondes lors du défilement.

Configurations et langues

  1. Nombre de configurations : combien de boutons de configuration afficher sur l’écran principal (1 à 6).
  2. Onglets de configuration : la configuration que vous modifiez. Les onglets des blocs « Langues » et « Boutons visibles » se dupliquent : en choisir un à l’un des deux endroits bascule les deux blocs.
  3. Langue source de la configuration choisie.
  4. Langue cible 1 de la configuration choisie.
  5. Langue cible 2 de la configuration choisie.
  6. Mémoriser les langues de l’écran principal : une seule case pour toutes les configurations. Lorsqu’elle est activée, les langues choisies sur l’écran principal sont inscrites dans la configuration active.

Boutons visibles

  1. Onglets de configuration : les mêmes que dans le bloc « Langues ».
  2. Boutons de la source : coller, copier, écouter, microphone, effacer.
  3. Boutons de la traduction 1 : copier, écouter.
  4. Boutons de la traduction 2 : copier, écouter.

Décochez une case et le bouton disparaît de l’écran principal pour cette configuration. Vous pouvez ainsi ne garder que ce dont vous avez besoin. Chaque configuration a son propre ensemble de boutons.

Microphone et réinitialisation

  1. Effacer le texte au démarrage du micro : une seule case pour tout. Le champ de saisie est vidé avant chaque dictée.
  2. Paramètres par défaut (🔄) : remet tous les paramètres à leurs valeurs d’origine.

Conseils utiles

  • Tous les paramètres sont enregistrés automatiquement et conservés après la fermeture du programme.
  • Les fenêtres d’aide et de paramètres se ferment avec le bouton ✕ ou la touche Esc.
  • Sur un téléphone, l’écran principal et les paramètres défilent par étapes : chaque balayage mène au bloc suivant.
  • Pour une paire de langues que vous utilisez souvent, créez une configuration séparée et ne gardez que les boutons dont vous avez besoin.
