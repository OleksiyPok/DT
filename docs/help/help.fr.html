Objet du programme

Dual Translator traduit le texte saisi simultanément en deux langues. Vous saisissez le texte une seule fois (en le tapant, en le collant ou en le dictant), et le programme affiche deux traductions côte à côte. Chaque résultat peut être copié ou écouté.

Pour les combinaisons de langues que vous utilisez souvent, il existe des configurations : chacune mémorise trois langues (la langue source et deux langues cibles) et un ensemble de boutons visibles. Vous passez de l’une à l’autre d’une simple pression.

L’interface est disponible en 13 langues : العربية, Čeština, Deutsch, English, Español, Français, Italiano, Nederlands, Polski, Português, Русский, Türkçe, Українська.

Écran principal

  1. Informations : ouvre cette fenêtre.
  2. Paramètres : ouvre la fenêtre des paramètres (voir « Paramètres »).
  3. Mode : le mode de couleurs de l’interface : Contraste, Normal, Soir ou Nuit. Chaque pression passe au mode suivant.
  4. Boutons de configuration : passage rapide entre les jeux de langues enregistrés (voir « Configurations »). Le bouton affiche le code de la langue source (par exemple NL, EN). La configuration active est mise en évidence.
  5. Langue source : la langue du texte que vous saisissez.
  6. Boutons au-dessus du texte : coller depuis le presse-papiers, copier le texte source, écouter le texte source.
  7. Champ de saisie : c’est ici que vous saisissez le texte source.
  8. Micro (, « Reconnaissance vocale ») : dictée dans la langue source. Appuyez de nouveau pour arrêter.
  9. Effacer () : supprime le texte source et les deux traductions.
  10. Traduction automatique : lorsque la case est cochée, la traduction apparaît toute seule dès que vous saisissez du texte ou changez de langue.
  11. Langue cible 1 et sa traduction. Les boutons et copient et lisent la traduction.
  12. Langue cible 2 et la seconde traduction, avec les mêmes boutons.

Mode d’emploi

  1. Choisissez la langue source et les deux langues cibles, ou appuyez sur le bouton de la configuration souhaitée.
  2. Tapez le texte, collez-le avec ou dictez-le avec le micro .
  3. Si la Traduction automatique est activée, les deux traductions apparaissent seules. Si elle est désactivée, appuyez sur le bouton Traduire.
  4. Copiez une traduction avec ou écoutez-la avec .
  1. Case « Traduction automatique » : décochez-la pour traduire uniquement avec le bouton.
  2. Bouton « Traduire » : visible uniquement lorsque la Traduction automatique est désactivée.

La traduction est effectuée par un service en ligne ; une connexion à internet est donc nécessaire. Les services gratuits peuvent imposer une limite quotidienne de volume de texte.

Saisie vocale et lecture

  • Dictée (). Appuyez sur le bouton et parlez dans la langue source. Le texte reconnu apparaît dans le champ de saisie. Une nouvelle pression arrête l’enregistrement. Le navigateur peut demander l’accès au micro, et dans certains navigateurs la dictée n’est pas disponible.
  • Lecture (). Lit à voix haute le texte source ou une traduction avec la voix de votre appareil. Appuyer de nouveau pendant la lecture l’arrête.
  • Effacement lors de la dictée. Dans les paramètres, vous pouvez faire vider le champ de saisie chaque fois que vous commencez à dicter.

Configurations

Une configuration mémorise trois langues (la langue source et deux langues cibles) et un ensemble de boutons visibles. Appuyer sur un bouton de configuration de l’écran principal charge immédiatement ses langues et ses boutons. Trois configurations sont disponibles par défaut ; on peut en activer jusqu’à six.

Si vous changez les langues directement sur l’écran principal, il s’agit d’un choix temporaire : la configuration enregistrée reste inchangée. Pour que ces changements soient mémorisés dans la configuration active, activez dans les paramètres « Mémoriser les langues de l’écran principal ».

Paramètres

La fenêtre des paramètres s’ouvre avec le bouton . Elle se compose de blocs ; le défilement permet de passer d’un bloc à l’autre, et une fraction dans le coin indique le numéro du bloc actuel sur le nombre total de blocs. Une modification est appliquée immédiatement.

Configurations

  1. Nombre : combien de boutons de configuration sont affichés sur l’écran principal, de 1 à 6.

Langues

  1. Onglets de configuration : la configuration que vous modifiez. Les onglets des blocs « Langues » et « Boutons visibles » se reflètent : un choix à un endroit change les deux blocs.
  2. Langue source de la configuration choisie.
  3. Langue cible 1 de la configuration choisie.
  4. Langue cible 2 de la configuration choisie.
  5. Mémoriser les langues de l’écran principal : une seule case pour toutes les configurations. Lorsqu’elle est cochée, les langues choisies sur l’écran principal sont enregistrées dans la configuration active.

Boutons visibles

  1. Onglets de configuration : les mêmes que dans le bloc « Langues ».
  2. Boutons de la source : coller, copier, écouter, micro, effacer.
  3. Boutons de la traduction 1 : copier, écouter.
  4. Boutons de la traduction 2 : copier, écouter.

Décochez une case et le bouton disparaît de l’écran principal pour cette configuration. Vous ne gardez ainsi que ce dont vous avez besoin. Chaque configuration a son propre ensemble de boutons.

Micro

  1. Bouton micro supplémentaire : affiche de grands boutons « Effacer » et « Micro » en bas de l’écran principal.
  2. Effacer le texte au démarrage du micro : le champ de saisie est vidé avant chaque dictée.

Interface, thème et mode

  1. Interface : la langue des libellés du programme.
  2. Thème : la palette de couleurs du programme.
  3. Mode : Contraste (plus lumineux et plus net), Normal, Soir ou Nuit. Le mode Nuit est sombre et atténué, pour regarder l’écran sans gêne dans l’obscurité. Il fonctionne en synchronisation avec le bouton « Mode » de l’écran principal.

Paramètres par défaut

  1. Paramètres par défaut () : remet tous les paramètres à leurs valeurs initiales.

Remarques

Tous les paramètres sont enregistrés dans votre navigateur et subsistent après la fermeture du programme.

Les fenêtres d’aide et de paramètres se ferment avec le bouton ✕ ou la touche Échap ; sur téléphone, aussi avec le bouton Retour. La touche F1 ouvre cette fenêtre.

Pour une paire de langues que vous utilisez souvent, créez une configuration dédiée et ne gardez que les boutons nécessaires.

Cette aide peut s’afficher dans n’importe quelle langue : choisissez-la dans le champ ci-dessus.
