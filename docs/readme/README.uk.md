# DT Dual Translator

Це компактний односторінковий застосунок, який перекладає текст одразу двома мовами.  
Введіть, вставте або надиктуйте текст один раз і читайте, копіюйте чи слухайте обидва переклади поруч.

<img src="img/app.png" alt="Зовнішній вигляд застосунку" width="360">

## Можливості

- Перекладає одразу двома мовами; зі ввімкненим автоперекладом переклади з’являються просто під час введення.
- До шести конфігурацій: швидкі вкладки на головному екрані, кожна запам’ятовує свої три мови та свій набір видимих кнопок.
- Голосове введення й озвучення вихідного тексту та обох перекладів, а також кнопки копіювання, вставлення й очищення.
- Використовує безкоштовний сервіс MyMemory, без облікового запису (діє добовий ліміт).
- Працює на телефонах і комп’ютерах, 13 мовами інтерфейсу, з 10 кольоровими темами в чотирьох режимах (звичайний, вечірній, нічний, контрастний).

## Налаштування

У вікні налаштувань є конфігурації (мови й видимі кнопки для кожної вкладки), мова інтерфейсу, тема й режим, а також скидання до типових значень.

<img src="img/settings.png" alt="Вікно налаштувань" width="360">
