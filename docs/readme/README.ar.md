# DT Dual Translator

<div dir="rtl">

هذا تطبيق مدمج من صفحة واحدة يترجم النص إلى لغتين في الوقت نفسه.  
اكتب النص أو الصقه أو أمله صوتيًا مرة واحدة، ثم اقرأ الترجمتين جنبًا إلى جنب وانسخهما أو استمع إليهما.
