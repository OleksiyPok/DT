# DT Dual Translator

<div dir="rtl">
هذا تطبيق مدمج من صفحة واحدة يترجم النص إلى لغتين في الوقت نفسه.  
اكتب النص أو الصقه أو أمله صوتيًا مرة واحدة، ثم اقرأ الترجمتين جنبًا إلى جنب وانسخهما أو استمع إليهما.
</div>

![مظهر التطبيق](img/app.png)

## المزايا

- يترجم إلى لغتين في وقت واحد؛ وعند تفعيل الترجمة التلقائية تظهر الترجمات أثناء الكتابة.
- حتى ست تهيئات: علامات تبويب سريعة في الشاشة الرئيسية، وكل منها يتذكر لغاتها الثلاث ومجموعة الأزرار الظاهرة الخاصة بها.
- إدخال صوتي وقراءة بصوت مسموع للنص الأصلي وللترجمتين، إضافةً إلى أزرار النسخ واللصق والمسح.
- يستخدم خدمة MyMemory المجانية دون حاجة إلى حساب (مع حد يومي).
- يعمل على الهواتف والحواسيب، بـ 13 لغة للواجهة، مع 10 سمات لونية في أربعة أوضاع (عادي، مسائي، ليلي، تباين عالٍ).

## الإعدادات

تضم نافذة الإعدادات التهيئات (اللغات والأزرار الظاهرة لكل علامة تبويب)، ولغة الواجهة، والسمة والوضع، وإعادة الضبط إلى الإعدادات الافتراضية.

![نافذة الإعدادات](img/settings.png)
