# DT Dual Translator

To kompaktowa, jednostronicowa aplikacja, która tłumaczy tekst jednocześnie na dwa języki.  
Wpisz, wklej lub podyktuj tekst tylko raz, a następnie czytaj, kopiuj lub słuchaj obu tłumaczeń obok siebie.
