# DT Dual Translator

Dies ist eine kompakte, einseitige Anwendung, die Text gleichzeitig in zwei Sprachen übersetzt.  
Text einmal eingeben, einfügen oder diktieren – und beide Übersetzungen nebeneinander lesen, kopieren oder anhören.

![Aussehen der Anwendung](img/app.png)

## Funktionen

- Übersetzt gleichzeitig in zwei Sprachen; bei aktivierter Auto-Übersetzung erscheinen die Übersetzungen schon während der Eingabe.
- Bis zu sechs Konfigurationen: Schnell-Tabs auf dem Hauptbildschirm, jeder mit seinen drei Sprachen und eigenen sichtbaren Schaltflächen.
- Spracheingabe und Vorlesen für den Quelltext und beide Übersetzungen, dazu Schaltflächen zum Kopieren, Einfügen und Löschen.
- Nutzt den kostenlosen Dienst MyMemory, ohne Konto (es gilt ein Tageslimit).
- Läuft auf Smartphone und Computer, in 13 Oberflächensprachen, mit 10 Farbthemen in vier Modi (normal, Abend, Nacht, Kontrast).

## Einstellungen

Das Einstellungsfenster enthält die Konfigurationen (Sprachen und sichtbare Schaltflächen je Tab), die Oberflächensprache, Thema und Modus sowie das Zurücksetzen auf Standardwerte.

![Einstellungsfenster](img/settings.png)

## Erste Schritte

Öffne die App im Browser: https://oleksiypok.github.io/DT/. Es muss nichts installiert werden, und deine Einstellungen werden im Browser gespeichert.
