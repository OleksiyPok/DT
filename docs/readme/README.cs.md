# DT Dual Translator

Toto je kompaktní jednostránková aplikace, která překládá text do dvou jazyků najednou.  
Text jednou napište, vložte nebo nadiktujte a oba překlady si přečtěte vedle sebe, zkopírujte nebo poslechněte.
