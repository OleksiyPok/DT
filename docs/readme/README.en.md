# DT Dual Translator

This is a compact, one-page application that translates text into two languages at once.  
Type, paste or dictate the text once and read, copy or listen to both translations side by side.

<img src="img/app.png" alt="Appearance of the application" width="360">

## Features

- Translates into two languages at once; with auto-translate on, the translations appear while you type.
- Up to six configurations: quick tabs on the main screen, each remembering its three languages and its own set of visible buttons.
- Voice input and reading aloud for the source text and both translations, plus copy, paste and clear buttons.
- Uses the free MyMemory service, no account needed (a daily limit applies).
- Works on phones and computers, in 13 interface languages, with 10 colour themes in four modes (normal, evening, night, contrast).

## Settings

The settings window holds the configurations (languages and visible buttons for each tab), the interface language, the theme and mode, and a reset to defaults.

<img src="img/settings.png" alt="Settings window" width="360">

## Getting started

Open the app in your browser: https://oleksiypok.github.io/DT/. Nothing needs to be installed, and your settings are saved in the browser.
